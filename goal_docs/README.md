## 📦 Installation

### Prerequisites
- PHP 8.1 or higher
- MySQL 8.0 or higher
- Redis (for caching and queues)
- Composer
- Node.js and NPM (for frontend assets)

### Quick Start
```bash
# Clone the repository
git clone https://github.com/your-username/goaldocs.git
cd goaldocs

# Install PHP dependencies
composer install

# Install frontend dependencies
npm install

# Copy environment file
cp .env.example .env

# Generate application key
php artisan key:generate

# Configure database in .env file
# DB_CONNECTION=mysql
# DB_HOST=127.0.0.1
# DB_PORT=3306
# DB_DATABASE=goaldocs
# DB_USERNAME=your_username
# DB_PASSWORD=your_password

# Run migrations
php artisan migrate

# Seed the database
php artisan db:seed

# Build frontend assets
npm run build

# Start the development server
php artisan serve
```

### Environment Configuration
```env
# Database
DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=goaldocs
DB_USERNAME=your_username
DB_PASSWORD=your_password

# Redis
REDIS_HOST=127.0.0.1
REDIS_PASSWORD=null
REDIS_PORT=6379

# SMS Service (Deywuro SMS)
DEYWURO_SMS_URL=https://api.deywuro.com/sms
DEYWURO_SMS_USERNAME=your_username
DEYWURO_SMS_PASSWORD=your_password
DEYWURO_SMS_SOURCE=GoalDocs

# File Storage
FILESYSTEM_DISK=local
# or for S3: FILESYSTEM_DISK=s3

# Mail Configuration
MAIL_MAILER=smtp
MAIL_HOST=smtp.mailtrap.io
MAIL_PORT=2525
MAIL_USERNAME=your_username
MAIL_PASSWORD=your_password
MAIL_ENCRYPTION=tls
MAIL_FROM_ADDRESS=noreply@goaldocs.com
MAIL_FROM_NAME="GoalDocs"
```
